  Persistent memory feature is validated upto 0~30GB in size.
  UMC error injection will cause system hang if the value of "NBIO SyncFlood Reporting" and "Reset after sync flood" modified from default.
  Four XGBE LED GPIO numbers should not be duplicated values and only unused GPIOs should be used for these LEDs otherwise behavior will be unknown.
  Persistent memory feature is validated upto 0~48GB in size. By default Pmem feature is disabled, To enable use persistent memory settings from "Amd CBS -> DF common options".
  LPDDR5 not supported by ABL.
