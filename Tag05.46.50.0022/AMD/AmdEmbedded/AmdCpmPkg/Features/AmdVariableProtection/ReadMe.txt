1. Integration

    1.1 Include below module in dsc and fdf files.
        AmdCpmPkg/Features/AmdVariableProtection/AmdVariableProtectionLib.inf
        AmdCpmPkg/Features/AmdVariableProtection/AmdVariableProtection.inf

    1.2 Set PcdAmdVariableProtectionTable for variables to be protected in Oem/Platform files.
        e.g.
        #
        # VariableName = AMD_PBS_SETUP_VARIABLE_NAME
        # VendorGuid   = gAmdPbsSystemConfigurationGuid
        #
        gAmdCpmPkgTokenSpaceGuid.PcdAmdVariableProtectionTable.ItemList[0].VariableName|L"AMD_PBS_SETUP"
        gAmdCpmPkgTokenSpaceGuid.PcdAmdVariableProtectionTable.ItemList[0].VendorGuid|{GUID({0xa339d746, 0xf678, 0x49b3, {0x9f, 0xc7, 0x54, 0xce, 0xf, 0x9d, 0xf2, 0x26}})}

        VariableName and VendorGuid is for protected variable name and guid

        AMD protect CBS, PBS and AOD setup variables by default, you can add other setup variables according to requirements.

    1.3 VariablePolicy and VarCheck mechanism will be enabled after EndOfDxe, so if you want to change these protected variables, you need to call
        AmdVariableProtectionLibSetLockState (AMD_VAR_UNLOCK) to unlock variable protection, and then call AmdVariableProtectionLibSetLockState (AMD_VAR_LOCK)
        to enable variable protection again after set variable.

2. Payload

    mDeletePayload and mCreatePayload are generated by PayLoadGenerateTool/GenerateTimeBaseVariable.efi.
    This is just the Test PayLoad in CPM module, customers could refer to the tool source to generate and use their own PayLoad.

    2.1 Understand and customize GenerateTimeBaseVariable\Src\GenerateTimeBaseVariable.c.
    2.2 Rebuild GenerateTimeBaseVariable.efi.
    2.3 Run "GenerateTimeBaseVariable.efi > output.log" in efi shell to generate new payload.

3. Statement

    AMD provides a relatively general implementation.
    If your source code architecture does not support it, or if you have other implementations, please protect CBS, PBS and AOD setup variables in your implementation.
