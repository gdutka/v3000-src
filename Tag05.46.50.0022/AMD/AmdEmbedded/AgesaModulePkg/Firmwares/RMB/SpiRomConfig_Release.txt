// How to check the support SPI List.
// Please check match with "Mfg_ID" and "mem_cap"
// For "mem_type" : 0xFF be common, else for specific device.
//

  How to check:
  Using the Depiprog SPI flash program to identify the JEDEC ID:
  It will list the Mfg_ID and JEDEC ID.
  example:
    Winbond W74M25JW
    Depiprog SPI read the JEDEC ID: 0xef6019
    Mfg_ID   : 0xef
    mem_type : 0x60
    mem_cap  : 0x19
  
  Mfg_ID List sample:
    0xef : winbond (W)
    0x90 : Macronix(MX)
    0xc2 : Macronix(MX)
    0x20 : Wuhan Xinxin Semiconductor Manufacturing Corp (XMC)
    0xc8 : GigaDevice (GD)
